# Further 业务界面视觉系统

> 状态：首轮完整基线，待整体评审

## 文档目的

本文把 [`interface-aesthetic-direction.md`](interface-aesthetic-direction.md) 中已确认的美学立场转化为可供设计、Agent 和 SwiftUI 实现共同理解的业务界面规则。

本文覆盖界面框架、排版、间距、色彩、形状、导航、操作、文案、动效、触感和无障碍。它暂不定义作品画布内部的记录点、印记、记录色、材质、构图和演化方式。

这里给出的色值、尺寸和时长是首轮完整基线。它们用于形成可以整体观看和修改的方案，不表示已经经过最终真机视觉验收。

## 视觉总述

Further 是一间用于审视自身的私人展厅。

界面以暮色为精神光源，空间承担约七成美学表达，排版承担约三成。大结构稳定，局部存在少量有意偏移；整体安静、冷静、深邃，可以带有慵懒和距离感。关键内容和操作在安静空间中局部清晰。

界面主动退色，把真正的色彩表达权留给跑步记录和作品。艺术性来自空间比例、留白、排版、边界、节奏和行为关系，不来自装饰、材质模拟或哲学口号。

## 设计令牌

### 间距

使用 4 pt 基础单位，建立有限但不机械重复的间距序列：

| 名称 | 数值 | 主要职责 |
| --- | ---: | --- |
| `space-1` | 4 pt | 同一文字组内的细小关系 |
| `space-2` | 8 pt | 图标与文字、标题与题签 |
| `space-3` | 12 pt | 紧密控件内部关系 |
| `space-4` | 16 pt | 普通行与控件间距 |
| `space-5` | 24 pt | 页面内容组之间 |
| `space-6` | 32 pt | 主要段落与区域之间 |
| `space-7` | 48 pt | 观看空间中的明显停顿 |
| `space-8` | 64 pt | 阶段分隔和大面积留白 |

页面不使用单一等距 `VStack` 贯穿全部内容。同一语义组紧密，不同职责之间明显放松；一屏中应至少出现一次 32–64 pt 的停顿，让空间具有呼吸。

### 页面边距与锚点

- iPhone 紧凑宽度下，主要安全内容边距以 20 pt 为基线。
- 文字阅读轴可以相对安全边距内移到 24 pt。
- 作品区域允许相对屏幕中心产生最多一个 `space-2` 的视觉偏移；偏移必须随从左到右或从右到左布局镜像。
- 底部主要行动距左右安全边缘 20 pt，距底部安全区域至少 12 pt。
- 顶部导航服从系统安全区域，不通过负间距贴近状态栏。
- Dynamic Type 达到辅助功能字号后，取消装饰性偏移，优先恢复单一清晰阅读轴。

### 界面色彩

色值使用 sRGB。记录色和作品画布不使用下表中的界面颜色替换。

| 职责 | 浅色模式 | 深色模式 |
| --- | --- | --- |
| 页面背景 | `#F2F1ED` | `#141414` |
| 次级平面 | `#EAE9E5` | `#1B1B1A` |
| 临时抬升平面 | `#FAF9F6` | `#222220` |
| 主要文字 | `#20201F` | `#E8E6E1` |
| 次级文字 | `#66645F` | `#A5A29B` |
| 弱结构（非文字） | `#85837D` | `#77746E` |
| 安静边界 | `#D4D2CC` | `#343330` |
| 清晰边界 | `#7C7871` | `#7C7871` |
| 主要行动平面 | `#E5E3DD` | `#272725` |
| 主要行动按下 | `#DCD9D2` | `#302F2C` |
| 破坏性操作 | `#B4232C` | `#FF6961` |

使用规则：

- 页面不设置常驻品牌强调色。
- 主要行动依靠位置、边界、面积和文字对比成立，不使用系统蓝。
- 次级文字必须保持可读，不能为了暮色氛围降到难以辨认。
- 弱结构色只用于非文字的辅助结构，不用于可见文字、状态和操作。
- 破坏性色只出现在结束确认等明确语义中，并控制面积。
- 系统权限或错误颜色必须同时配合文字、形状或结构提示。
- “提高对比度”开启时，安静边界提升为清晰边界，次级文字向主要文字靠近一个明度层级。

## 排版系统

首版只使用 Apple 系统字体，不引入品牌字体。所有文字采用 SwiftUI 语义字号并支持 Dynamic Type；下列点数只描述默认尺寸下的视觉基线。

| 角色 | SwiftUI 语义 | 默认倾向 | 用途 |
| --- | --- | --- | --- |
| 阶段事件 | `largeTitle` | 34 pt，Regular | 极少数作品阶段变化 |
| 页面标题 | `title2` | 22 pt，Medium | 当前空间身份 |
| 作品题名 | `title3` | 20 pt，Regular | “这一幅”等作品身份 |
| 区域标题 | `headline` | 17 pt，Medium | 必要的表单或状态分区 |
| 正文 | `body` | 17 pt，Regular | 说明和短记 |
| 题签 | `subheadline` | 15 pt，Regular | 周期、日期和作品边界 |
| 辅助事实 | `footnote` | 13 pt，Regular | 距离、时间来源和权限说明 |
| 跑步计时 | 自 `largeTitle` 缩放 | 52 pt，Semibold，Rounded | 运动中活动时间 |

排版规则：

- 常规字重优先；除跑步计时和选中强调外，不使用 Bold 作为默认层级手段。
- 不使用全大写、宽字距标题或刻意模仿美术馆标牌的英文排版。
- 题签与标题可以不共享同一轴线，但必须保持明确的阅读先后。
- 跑步计时使用等宽数字，避免数字变化导致布局跳动。
- 阶段事件最多两行，不通过缩小字体塞入一屏。
- 辅助功能字号下，事实行从左右结构重排为上下结构。

## 形状、边界与平面

### 内容边界

- 作品和普通内容接近直线，不使用大圆角卡片。
- 画布外框基线采用 1 pt 安静边界；圆角暂定 2 pt，后续可随装裱语言调整为 0–4 pt。
- 列表使用空间和细分隔线组织，不把每条记录包装成卡片。
- 页面不使用装饰性阴影。只有系统浮层、键盘上方辅助面板等真实抬升关系可以出现系统阴影。

### 操作边界

- 主要按钮圆角 14 pt，最小高度 52 pt。
- 普通按钮圆角 12 pt，最小可触控区域 44×44 pt。
- 输入框圆角 10 pt，使用安静边界；聚焦时提升为清晰边界，不改变为彩色描边。
- 颜色选择控件的形状和选中表现留到感受色视觉阶段确定，但选中不能只依赖颜色。
- 不使用全胶囊按钮，除非控件语义确实是紧凑切换或过滤；首版业务界面暂无此需要。

## 当前作品的空间骨架

当前作品是唯一主空间，采用已经确认的 N2 导航关系。

### 顶部边缘

- 左侧为文字入口“回望”。
- 右侧为系统设置图标，VoiceOver 名称为“设置”。
- 二者不使用可见底板；通过 44×44 pt 隐形触控区域保证可用性。

### 作品身份

- 可见作品题名暂定为“这一幅”，替代工具式大标题“当前作品”。
- 周期信息作为题签，例如“三个月作品”或“半程马拉松作品”。
- “作品集”作为明确文字入口，与作品题名或周期题签位于同一身份区域，但不与回望和设置组成导航栏。
- 作品集入口不能使用切换器、下拉箭头或分页样式，避免被理解为切换当前作品。

### 画布

- 页面为画布保留约 4:5 的纵向区域，作为首轮布局基线。
- 画布在空白、积累中和已完成状态保持相同结构位置。
- 空白画布内部没有文字、图标、颜色或示例印记。
- 空白说明位于画布之外：“第一次跑步会让作品从这里开始。”
- 页面布局不依赖画布内部内容才能成立。

### 主要行动

- 主要行动位于底部安全区域，使用“安静边界”样式。
- 默认使用主要行动平面、1 pt 清晰边界和主要文字，不使用高饱和色。
- 按下时只在局部提高平面和边界对比，不放大、弹跳或发光。
- 空白与积累中可见文字暂定为“出发”，VoiceOver 名称为“准备开始跑步”。
- 已完成状态可见文字暂定为“开启下一幅”，VoiceOver 名称为“选择下一作品周期”。

## 图标规则

- Further 自身的行动、导航和阶段关系优先使用文字。
- 返回、关闭、设置、展开和播放控制等稳定系统操作使用 SF Symbols。
- 图标默认 17–20 pt，不用超大图标填补空白。
- 不自创抽象图标表达回望、作品、感受或沉默。
- 陌生含义必须有可见文字；图标按钮始终提供 VoiceOver 名称。
- 图标颜色服从文字层级，不建立独立彩色图标系统。

## 文字人格与工作词表

### 总体语气

- 少、准、留有余味。
- 不评价用户，不解释人生意义，不制造励志或疗愈语气。
- 文学性来自词的选择，不来自长句、隐喻堆叠或哲学引语。
- 安全、权限、缺失和技术中断使用直接事实语言。

### 职责词汇

| 职责 | 语义来源 | 首轮工作文案 |
| --- | --- | --- |
| 当前作品身份 | 时间与观看 | 这一幅 |
| 准备跑步 | 行进 | 出发 |
| 正式建立跑步会话 | 明确操作 | 开始跑步 |
| 运动状态 | 行进 | 途中 |
| 暂停状态 | 明确状态 | 已暂停 |
| 恢复运动 | 明确操作 | 继续 |
| 结束运动 | 明确操作 | 结束 |
| 浏览历史记录 | 观看 | 回望 |
| 返回更新后的作品 | 观看 | 回到作品 |
| 选择感受色 | 表达 | 这一刻，是什么颜色？ |
| 短记 | 表达 | 写下此刻 |
| 不选择颜色 | 表达 | 保持沉默 |
| 完成表达 | 表达与锁定 | 留下这一刻 |
| 记录进入作品 | 时间与痕迹 | 它已进入这一幅 |
| 开始下一作品周期 | 行进与章节 | 开启下一幅 |

“开始跑步”“暂停”“结束”等涉及会话生命周期的文字保持直接，不为统一文学性而改写成含糊意象。工作文案需要在完整页面和本地化阶段继续验证，但 Agent 不得自行改回激励、训练或数据工具语气。

## 动效系统

### 行动节奏

- 按下、选中、暂停和继续反馈：120–180 ms，`easeOut`，不使用弹性回弹。
- 操作引发的数据状态立即改变，动画不能延后真实反馈。
- 禁止按钮缩放弹跳、发光和循环脉冲。

### 观看节奏

- 普通页面推进和返回：280–360 ms，平静的 `easeInOut`。
- 空间转场优先使用轻微位移配合透明度，不旋转、不翻卡、不大幅缩放。
- 返回时保持方向连续，让用户感知自己回到先前空间。

### 阶段事件

- 第一条记录使作品开始、记录进入作品、作品完成和开启下一幅：700–1200 ms 的完整状态过程，可以包含短暂停留。
- 阶段事件只表达“已经发生并不可逆”，不使用彩纸、粒子、烟花、徽章或成功勾选庆祝。
- 事件文字出现一次后回到题签声量，不成为首页永久大标题。

### 减弱动态

- 删除空间位移、缩放和连续形变。
- 使用 100–160 ms 的局部透明度或对比变化，或者直接切换到稳定终态。
- 同时提供简短文字确认，说明记录已进入作品或作品已经完成。
- 不依赖动画播放完毕才能继续操作。

## 触感

- 普通浏览、打开回望、作品集和设置不使用触感。
- 正式开始跑步使用一次中等确认触感。
- 暂停和继续使用轻量触感，二者保持一致。
- 确认结束使用一次中等确认触感，不使用错误或警告式连续震动。
- 感受色选择可以使用轻量选择触感；切换颜色不叠加多次反馈。
- 完成表达使用一次克制的确认触感，不使用“成功奖励”触感序列。
- 减弱动态不会关闭必要触感；系统关闭触感时不以其他刺激补偿。

## 各业务空间的应用

### 作品周期选择

- 保持单一阅读轴和充足留白，不把六个选项做成营销卡片。
- 时间作品与里程碑作品以题签式分组和安静边界区分。
- 选中状态同时使用位置、边界和系统选中标识，不只改变颜色。
- 主要行动位于底部；首次进入没有返回，开启下一幅时保留明确返回。

### 跑步环境与准备

- “室外”“室内”是两个清晰选择，不使用风景插画或运动人物大图。
- 选择环境不立即建立记录；正式“开始跑步”保持直接文案。
- 定位不可用说明紧邻室外语境，以事实语言呈现，不显示错误红色大卡片。

### 倒数与跑步追踪

- 倒数使用大号等宽数字和空旷背景，不增加环形进度、脉冲或激励文字。
- 追踪页以活动时间为第一视觉事实，距离为第二事实。
- “途中”或“已暂停”作为明确状态文字；暂停不能只靠颜色。
- 暂停/继续是当前主要操作，结束保持清晰但较低声量；结束确认后不可返回跑步状态。
- 运动中减少装饰性不对称，保证晃动视线和单手触控下的稳定。

### 感受收束

- 页面从运动中的功能空间回到安静、向内的表达空间。
- 问句“这一刻，是什么颜色？”可以承担页面标题，但不加入情绪标签或解释。
- 短记入口“写下此刻”保持可选，不制造表单任务感。
- “留下这一刻”是主要行动，“保持沉默”明确可见但较低声量。
- 感受色具体数量、色值、形状和选择布局留到作品色彩阶段。

### 室内距离

- 恢复直接、朴素的输入语言，不延续不必要的抒情表达。
- 单位与输入值使用清晰基线关系；未知和跳过不显示为零或错误。
- 跳过是明确次级行动，不形成待办或警告。

### 记录进入作品

- 使用阶段事件声量，而不是运动总结页。
- 首轮工作文字为“它已进入这一幅”，不显示本次成绩摘要或作品记录数量。
- 主要行动“回到作品”明确结束连续流程。
- 具体印记进入方式和作品完成美术动效保持开放。

### 回望与单次记录

- 回望是时间索引，使用连续列表、月份题签和充分行距，不使用统计卡片。
- 每行先呈现记忆身份和短记，再以低声量展示日期、距离与时间。
- 单次记录以感受和短记为视觉中心；事实使用题签和安静分隔组织。
- 路线存在时不自动成为页面主视觉；缺失时使用直接文字，不放置错误占位图。

### 作品集与已完成作品

- 作品集像私人收藏索引，不像照片网格、成就墙或排行榜。
- 单幅作品缩略图保留完整边界和呼吸，不叠加成绩角标。
- 已完成作品页面让作品先被观看，周期与事实作为题签存在。
- 不提供分享、编辑、删除或导出图片入口。

### 设置与阻断状态

- 设置保持朴素原生，不承担品牌展示。
- 权限状态和系统设置入口直接陈述事实，不使用美术化隐喻。
- 数据无法打开等阻断状态优先清楚说明发生了什么和用户可以做什么；视觉气质让位于恢复能力。

## 无障碍基线

- 所有文本使用 Dynamic Type；不使用固定像素文字模拟可缩放界面。
- 辅助功能字号下允许页面滚动，事实行垂直排列，底部主要行动不能覆盖内容。
- VoiceOver 阅读顺序保持稳定的顶部至底部功能序列，不因视觉偏移而随机变化；视觉顺序和辅助技术顺序不能表达互相矛盾的层级。
- 可见文学文案和 VoiceOver 功能名称可以不同，但二者不能表达不同结果。
- 画布至少提供作品状态、记录数量和是否完成的整体摘要；逐个印记探索后续决定。
- 所有触控区域至少 44×44 pt；运动中主要操作优先达到 52 pt 或更大。
- “区分而不只靠颜色”：选中、暂停、权限、技术中断和完成均需文字或形状支持。
- 支持减弱动态、提高对比度、减弱透明度和从右到左布局。
- 开启减弱透明度时，临时抬升平面使用不透明背景和清晰边界，不依赖背景模糊表达层级。
- 深色原点不能成为强制外观；界面跟随系统模式，用户无需在 App 内选择主题。

## 验收标准

1. 将画布内部替换为纯中性矩形后，页面仍具有完整、明确的 Further 气质。
2. 移除所有作品色后，仍可辨认主要行动、次级入口和状态层级。
3. 当前作品首先由空间占比和留白成为视觉中心，而不是依赖彩色内容。
4. 页面不存在等权顶部导航栏、底部标签栏或卡片式仪表盘。
5. 主要行动明确可操作，但不是页面中唯一大面积高亮色块。
6. 普通页面大部分文字保持题签声量；只有已定义阶段事件使用展示性文字。
7. 暮色空间没有霓虹、星空、科技夜跑或日落渐变等直白符号。
8. 不对称看起来有意且从容；辅助功能字号下可以回归稳定单轴。
9. 运动中的操作即时、清晰，不被观看空间的慢节奏拖延。
10. 浅色模式保留同一空间人格，而不是变成默认白色工具界面。
11. 所有缺失、权限拒绝、技术中断和阻断状态都能在不依赖颜色的情况下理解。
12. 任何未定义的作品美术问题都保持开放，不由 Agent 使用常见生成艺术样式补全。

## 仍然开放

- 作品画布的最终比例是否继续使用 4:5；
- 作品边界最终采用 0–4 pt 中的哪种圆角；
- 感受色和沉默记录色；
- 印记、构图、演化和装裱；
- 作品相关阶段事件的具体视觉内容；
- 记录色与界面中性色的最终屏幕色彩管理；
- 本文工作文案的最终英文版本与本地化语气。
