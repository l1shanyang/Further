# Further 业务界面视觉系统

> 状态：首版原生基线；待按完整状态流制作真机稿

## 文档目的

本文把 [`interface-aesthetic-direction.md`](interface-aesthetic-direction.md) 转换为可以由设计
与 SwiftUI 实现共同执行的规则。它定义业务界面，不定义作品画布内部的颜色、印记、
材质、构图或生成方式。

## 1. 平台基线

- 目标设备优先验证 iPhone 13 mini，系统为当前项目支持的 iOS。
- 第一正式版本只设计浅色外观，只验收系统标准文字大小。
- 页面使用 Apple 系统字体、SF Symbols、系统语义颜色和原生组件。
- 不建立独立的间距、圆角、阴影、材质和动效令牌系统。
- 系统组件的默认尺寸、形状、内边距和交互状态是基线；只有真实业务问题才能申请例外。

SwiftUI 中，“使用原生”意味着优先组合 `NavigationStack`、`List`、`Form`、`Section`、
`Button`、`Picker`、`TextField`、`sheet`、`confirmationDialog` 和 `alert`，而不是先绘制一
套视觉相似的自定义组件。

## 2. 色彩与材质

### 业务界面

- 页面使用系统浅色背景和分组背景，不写死自定义米白、灰黑或暮色色值。
- 文字使用 `primary`、`secondary` 等系统语义层级；分隔使用系统 separator 语义。
- 可交互元素使用系统 tint。首版不定义品牌强调色，主要行动使用系统 prominent 样式。
- 错误和破坏性操作使用系统 destructive 语义，不另建功能色。
- 不用颜色同时表达业务内容和可交互性；作品颜色只属于作品。
- 导航与控件使用系统在当前 iOS 上提供的材质表现，不把 Liquid Glass 用到内容背景或
  自定义卡片中。

### 作品区域

在作品视觉尚未确定时，画布占位只使用系统背景与细分隔边界。内部保持真实空白，不放
说明、图标、示例颜色或预设结果。画布最终可以自定义，但不得把颜色扩散到工具栏和业务
控件，使系统交互与作品内容混淆。

## 3. 排版与文案

- 只使用 SwiftUI 语义文字样式，不在规范中指定自定义点数、字距或字体粗细组合。
- 导航标题由系统导航栏呈现；区域标题使用 `headline`，正文使用 `body`，辅助事实使用
  `secondary` 层级的 `subheadline` 或 `footnote`。
- 计时数字可以使用系统等宽数字，保证变化时不跳动；不引入展示字体。
- 一段辅助说明优先控制在两行内；如果页面需要多段解释，先检查流程或命名是否有问题。
- 关键动作使用直接动词：开始跑步、暂停、继续、结束、完成、跳过、打开设置。
- 保留领域词“回望”；作品标题和题签可以有少量意象，但不能影响导航和操作预判。
- 权限、缺失、技术中断和不可逆确认全部使用事实文案。

首版虽然不验收大号字体版式，仍使用语义字体，避免为未来支持制造固定字号债务。

## 4. 布局与层级

- 内容服从安全区域和系统默认内容边距，不用负间距贴边。
- 使用系统导航栏建立页面身份和返回关系，不在内容区重复绘制标题栏。
- 普通页面采用一个稳定的纵向阅读轴；不为“随性”制造偏移、错轴或不等距。
- 组间距离由系统容器和标准 SwiftUI spacing 产生。不要用巨大留白代替层级。
- 一屏只有一个 prominent 主要行动。次要操作使用普通按钮、列表行或 toolbar item。
- 按钮不通过自定义高度、圆角、边框和阴影重塑；运动中的核心操作只扩大系统按钮的
  content shape 和可触控范围。
- 不把普通内容放进卡片。只有作品画布、地图、系统弹层等确有独立边界的对象使用容器。

## 5. 导航与呈现

### 当前作品根空间

- 使用系统 `NavigationStack`，导航标题为“当前作品”，不自绘大标题。
- “回望”和“作品集”使用文字 toolbar item，设置使用熟悉的 `gearshape` SF Symbol 并
  提供“设置”辅助功能名称。
- 三个入口持续可见，但由系统 toolbar 分组和呈现，不做网页式等权横向导航，也不增加
  底部标签栏。
- 画布是内容区最大单体，保持稳定位置和边界；画布外只显示必要的周期题签与状态说明。
- 底部只有一个系统 prominent 按钮：空白或积累中为“开始跑步”，完成后为
  “开始下一幅作品”。

若 iPhone 13 mini 上 toolbar 拥挤，优先调整系统 toolbar placement、缩短标题，或把其中
一个入口重新分配到内容区的可见层级；三个入口本身仍须可见。不得把“回望”或“作品集”
改成陌生图标，也不得用隐藏菜单解决拥挤。最终方案必须在真机验证可发现性后确定。

### 页面推进、sheet 与确认

- 稳定空间使用页面推进：周期选择、回望、单次记录、作品集、已完成作品、设置。
- 短暂且完成后返回当前上下文的选择可使用 sheet：跑步环境、感受收束、室内距离。
- 不可逆或危险选择使用系统 confirmation dialog 或 alert：结束跑步等。
- sheet 打开后使用系统焦点与关闭行为；不自制半屏弹层，不让所有次级空间都变成 sheet。
- 收束流程不得通过交互式下拉意外丢弃已经成立的记录。

## 6. 页面组件映射

| 空间 | 首选原生结构 | 唯一自定义内容 |
| --- | --- | --- |
| 作品周期选择 | `List`/`Form` + `Picker` + prominent `Button` | 无 |
| 当前作品 | `NavigationStack` + 普通内容布局 + prominent `Button` | 作品画布 |
| 跑步环境 | `sheet` + 两个清楚的选择行 | 无 |
| 倒数与追踪 | 全屏内容 + 系统按钮 | 计时的内容层级，不自绘仪表盘 |
| 结束确认 | `confirmationDialog` 或 `alert` | 无 |
| 感受收束 | sheet/页面 + 系统文本输入 | 感受色选择器 |
| 室内距离 | `TextField` + 数字键盘 + 系统按钮 | 无 |
| 记录进入作品 | 稳定内容页或覆盖层 | 作品更新反馈 |
| 回望 | `List` + `Section` + `NavigationLink` | 无 |
| 单次记录 | 普通详情布局；有路线时使用 MapKit 视图 | 记录色样本 |
| 作品集 | `List` 或简洁网格 + `NavigationLink` | 作品缩略图 |
| 设置 | `Form` + `Section` + `Picker` + 系统设置链接 | 无 |

表格描述的是语义结构，不要求每页机械使用相同容器。设计稿若为上述普通能力创建了
自定义卡片、选择器或导航组件，需要说明系统组件不能满足的具体原因。

## 7. 状态表达

- 空白：画布内部保持空白，说明放在画布外；不使用空状态插画。
- 加载：仅在确有等待时使用系统 `ProgressView`，不为瞬时本地读取制造加载页。
- 缺失：直接省略不成立的事实，或显示“未记录”；不显示零值和错误占位图。
- 权限拒绝：在相关位置说明影响，并提供系统设置入口；不使用整页红色警告。
- 技术中断：使用一次性、可读的系统式说明；不形成角标、待办或恢复流程。
- 完成：作品继续停留，主要行动变为“开始下一幅作品”；不出现奖章、彩纸或成绩总结。
- 选中、暂停、完成和错误不能只靠颜色，必须有文字、系统选中标记或结构变化。

## 8. 动效与触感

- 导航、sheet、dialog、按钮反馈全部使用系统默认动效，不重设统一时长或缓动。
- 普通业务状态变化优先直接更新内容，不增加淡入、滑动、缩放或弹性回弹。
- 触感只用于开始、暂停/继续、确认结束和完成表达等需要确认的动作，使用系统反馈类型。
- 记录进入作品与作品完成允许自定义动效，但在作品美术确定前保持开放。
- 任何自定义动效都要提供 Reduce Motion 下的稳定终态与文字确认；业务完成不能依赖动画
  播放结束。

## 9. 首版可访问性范围

首版必须做到：

- 所有控件具有准确的 VoiceOver 名称、值和阅读顺序；
- 作品画布提供整体摘要，不要求逐个印记探索；
- 默认触控目标采用 iOS 推荐的 44×44 pt，运动中主要操作在此基础上保持足够间距；
- 状态、选择和错误不只依赖颜色；
- 自定义动效响应 Reduce Motion；
- 文本与图标在浅色外观下保持可靠对比。

本轮不把以下内容列为视觉验收项：辅助功能大字号下的专项重排、深色模式配色与作品身份
转译。它们是明确延期，不得在交付说明中写成“已支持”。

## 10. 真机验收

每个正式页面至少在 iPhone 13 mini 浅色外观、标准字号下验证：

1. 第一眼能说出页面身份、主要内容和唯一主要行动；
2. 系统控件看起来并表现得像当前 iOS，而不是近似复刻；
3. 移除画布内容后页面仍清楚，恢复画布内容后作品明显成为主角；
4. 没有自定义背景、卡片、圆角或动效与内容竞争；
5. 文案能够预判结果，不需要解释设计隐喻；
6. 空白、缺失、权限拒绝、技术中断和完成状态都不是只在理想路径截图中成立；
7. VoiceOver 能按业务顺序完成主要流程；
8. 运动中能单手找到暂停、继续、结束和确认；
9. Reduce Motion 下关键状态变化仍然明确；
10. 未决定的作品美术没有被临时视觉冒充。

## 11. 仍然开放

- 作品画布比例与最终边界；
- 感受色、沉默记录色和选择器；
- 印记、构图、材质、演化、完成和装裱；
- 距离、配速是否影响作品形式；
- 记录进入作品与作品完成的专属动效。
