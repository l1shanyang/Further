# Further 界面美学方向

> 状态：2026-09 真机评审后重置并确认

## 为什么重置

上一轮把“私人展厅、暮色、空间七成、排版三成、稳定中的偏移”等感受过早转换成了
专用色值、非标准排版、特殊导航、定制按钮和大量参数。单独看设计稿时这些规则能形成
风格，进入真实 iPhone 后却同时争夺注意力，界面既不像自然的 iOS，也没有让作品真正
成为主角。

这次失败说明：Further 需要的是明确的内容人格，不是一套覆盖平台语言的视觉人格。
旧方向作为探索结论被否决，不再作为后续 Agent 的设计依据。

## 新的美学命题

Further 是一个安静地查看自身跑步痕迹的 iPhone App。

它的深度来自真实记录在时间中的累积，而不是深色背景、诗意文案、特殊材质或不对称
版式。它的克制来自清楚的取舍：一屏只突出一件事，事实不被包装成成绩，系统能力不被
包装成品牌组件。

界面本身保持清醒、朴素、精确。作品可以深邃、偶然、感性；承载作品的界面不替作品
表演。

## 气质词与可观察行为

| 气质 | 界面中的实际表现 |
| --- | --- |
| 安静 | 同时只出现一个 prominent 行动，不用常驻动画和大面积强调色 |
| 克制 | 优先系统组件，减少容器、装饰和重复说明 |
| 私人 | 不比较、不分享、不评价；历史只服务用户自己的回望 |
| 深思 | 允许观看作品停留，不用催促、进度和奖励打断 |
| 可靠 | 跑步、权限、缺失和中断状态直接说明，操作立即反馈 |

“冷淡”可以存在于内容密度和语气中，不能通过低对比、难懂文案、小触控区或隐藏入口
实现。“随性”如果无法用稳定布局和平台行为表达，就不作为业务界面目标。

## Apple 设计参考的使用方式

参考 Apple Design Award 获奖作品只用于校准原则，不拼贴视觉特征，也不引入它们的
产品能力。研究记录与官方出处见
[`../research/apple-native-design-references.md`](../research/apple-native-design-references.md)。

当前借鉴重点是：

- 从 Gentler Streak 借鉴对运动的非评判态度和一致、低刺激的信息表达；不借鉴训练建议、
  统计总结或鼓励机制。
- 从 Bears Gratitude 借鉴让自我表达保持轻松、诚实且容易进入；不借鉴每日习惯、角色插画、
  提醒或奖励。
- 从 Crouton 借鉴活动场景中“一眼找到当前事实与操作”的信息层级；不借鉴食谱结构和功能密度。

这些案例都不是 Further 的视觉模板。Apple 官方组件与 HIG 始终高于案例表面的颜色、
布局和动效。

## 艺术性放在哪里

### 业务界面

艺术性只表现为编辑判断：什么出现、什么不出现，什么先读到，哪里允许内容停留。它不
承担独立的材质、调色或装饰体系。

### 作品内容

作品画布承担 Further 的主要美学表达。感受色、沉默记录、印记、时间演化和完成形态都
属于作品设计阶段。业务界面只提供稳定、无污染、可替换的承载空间。

### 文字

操作文字以明确为先。只有作品题名、周期题签和回望中的记忆文字可以保留少量意象。
不再用“出发”“这一幅”等词替换需要准确预判的“开始跑步”“当前作品”，除非后续用户
测试证明它同样清楚。

## 第一正式版本的视觉边界

第一正式版本使用一套浅色视觉和系统标准字号。这样做是主动缩小设计变量，使真机评审
先回答层级、密度、原生感和作品主次是否成立。

这不表示无障碍不重要：VoiceOver、触控范围、状态不只依赖颜色、减弱动态仍需成立；
代码使用语义字体，为后续 Dynamic Type 阶段保留正确入口。深色模式和大号字体的视觉
适配在后续单独设计、验证，不在本轮用未经评审的自动结果冒充完成。

## 明确不再采用

- “私人画廊”“暮色”作为组件造型、背景颜色或导航布局的直接隐喻；
- 70/30、N2、局部偏移等无法由系统布局自然支持的构图规则；
- 自定义中性色阶、圆角阶梯和动效时长表；
- 为了显得克制而取消系统蓝、弱化按钮边界或降低文字对比；
- 用诗性词汇替换关键业务动作；
- 让纯空白业务界面也必须表现强烈品牌风格的验收要求；
- 同时制作浅色、深色、标准字号和大号字号导致首轮判断失焦。

## 尚未决定

以下仍属于作品美术，而不是本次业务界面规范：

- 记录点、印记、原始记录色与沉默记录色；
- 感受色数量、色值和选择表现；
- 画布材质、构图、演化、完成和装裱；
- 距离、配速是否参与作品形式；
- 新记录进入作品与作品完成的专属动效。
